# Question batches (bilingual rehearsal view)

Practice prompts for behavioral rounds. **EN** = English; **PT** = Portuguese (same intent).

## Section A — highest-risk prompts

Domains where you may have no clean STAR. Lead with a short boundary when the prompt does not match your history, then offer the closest real story.

### Adaptability / change

| EN (prompt family) | PT (família de pergunta) |
| --- | --- |
| Sudden priority shift; reorg; cancelled work after heavy investment | Mudança súbita de prioridade; reorg; projeto cancelado depois de muito esforço |
| New manager or new stack mid-project | Novo gestor ou nova stack no meio do projeto |

**Boundary (EN):** "I don't have a clean 'leadership flipped the roadmap' story; I'd name the closest real change and what I did."

**Boundary (PT):** "Não tenho um caso limpo de 'liderança virou o roadmap'; eu digo a mudança real mais próxima e o que fiz."

### Customer / user / trust

| EN | PT |
| --- | --- |
| Failed a customer; lost trust; mis-set expectations | Falhei com cliente; perda de confiança; expectativa errada |
| Reduced recurring pain for users | Reduzi dor recorrente para usuários |

**Boundary (EN):** "No single dramatic 'trust break' STAR; I'd name limits before claiming a big customer failure."

**Boundary (PT):** "Não tenho um STAR forte de 'quebra de confiança'; eu digo os limites antes de dramatizar."

## Section B — strongest anchors

Prepare one story per prompt family; keep each to ~2 minutes.

- ownership / delivery
- prioritization / tradeoffs
- conflict / disagreement
- failure / mistakes / learning
- mentoring / enabling others
